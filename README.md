# 人生问题求解器

站在前人的经验之上，把一团乱麻的问题整理成可以选择、行动和复盘的方案。

它会帮你区分事实与假设，指出盲区，借鉴相关经验，并明确建议在什么条件下不再适用。结果通常包含：**问题本质 → 前人智慧 → 最优策略 → 行动方案 → 认知升级**。关键信息不足时先少量追问。

## 安装

把下面这句话交给你的 Agent：

```text
请帮我安装这个 Skill：https://github.com/Tangerine-Cat888/life-problem-solver
```

也可以通过命令安装：

```sh
npx skills add Tangerine-Cat888/life-problem-solver
```

这条可选安装命令需要 Node.js 和网络；Skill 本身不需要 Node.js。手动安装时，下载仓库，将整个目录放入宿主的技能目录，按宿主方式刷新或重启。仓库根目录的 [SKILL.md](SKILL.md) 是技能入口。

## 使用

无需账号、密钥或额外配置。直接说：

> 用人生问题求解器帮我分析：我在准备转行，每周能拿出六小时。学了两个月但还没有作品。我该继续上课还是开始做项目？希望三个月后能判断是否适合这条路。

尽量补充四项信息：

- 背景、目标和不能妥协的底线。
- 已经尝试过的动作与客观结果。
- 可用的时间、精力、资金，以及不能承受的代价。
- 眼前最需要决定的事情。

不必一次说全，也不用重复提供已有对话内容。执行后可以继续带着真实反馈回来复盘。

## 能力与边界

重点是提高决策过程的清晰度，不保证结果，不替用户决定人生价值。直接指出问题不等于贬低人格，推测的心理动机不能当作诊断。

医疗、法律和重大财务后果需要相应专业判断；本技能不代替专业服务。纯知识问答、单纯情绪陪伴、润色和 Skill 制作交给普通对话或相应技能。

默认结果留在对话中，不建立个人档案，不自动发送消息、购买、报名或修改账号。查证资料时只向宿主可用的检索服务发送必要的抽象关键词，不发送私人经历与财务明细。对话和检索服务的数据处理仍受各自隐私政策约束，使用成本取决于宿主与模型。

## 兼容性

核心为通用 Markdown 指令，无系统脚本依赖。宿主需要能够读取并执行技能指令。有检索能力时核验来源；没有时标注不确定性，不能把未核实内容冒充可靠出处。

Windows 环境已完成文件校验与独立执行对照。其他操作系统、不同宿主和弱模型效果未验证；静态通用性检查不等于这些环境已实测。无需图形界面或子 Agent 即可使用；离线时来源核验能力受限。

## 测试与排查

[evals/evals.json](evals/evals.json) 包含三个通用请求：具体决策、信息不足、仅需润色。可在独立对话中分别加载和不加载技能运行同样请求，再按 expectations 检查结果；整体清晰度与语气由使用者判断。

初次对照中，两组都满足九项明确行为要求，小样本不能证明整体优于普通回答。没有精确 Token 数据，不提供成本优势声明。

无法触发时先检查宿主是否加载该目录，并显式点名“人生问题求解器”。无法核验来源时，应保留不确定性或提供可核实材料。遇到问题可提交 [Issue](https://github.com/Tangerine-Cat888/life-problem-solver/issues)，请先移除私人信息。
